# Grafolão 2026 🏆

Sistema de bolão da Copa do Mundo 2026 com análise de grafos.

Desenvolvido como trabalho da disciplina - Introdução à Teoria dos Grafos (UFAM, 2026/01).

## Propostas implementadas

- **Proposta 2** — Grafo de Confrontos entre Participantes (PageRank, ciclos)
- **Proposta 4** — Caminho Mínimo para o Título (DAG, Dijkstra, fluxo)
- **Proposta 5** — Cliques e Panelinhas (clique máxima, grafo bipartido)

## Stack

- Frontend: Vite + React + TypeScript + Tailwind CSS
- Backend: Fastify + TypeScript
- Banco de dados: PostgreSQL (Supabase)
- Visualização: Sigma.js + Graphology

## Como rodar

```bash
docker compose up
```
